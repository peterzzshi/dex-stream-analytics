## Git Workflow

Never commit unless explicitly asked. Always ask before committing.

## Documentation

Verify every referenced file, test name, command, and dependency exists. Keep AGENT.md/SESSION-HANDOFF.md concise (<60
lines); no plans, progress logs, or auto-commit behavior.

## Scope Discipline

Present proposed changes before refactoring beyond the scope of a review/analysis request.

## Testing

Tests assert behavior and outcomes, not implementation. Every test must contain a real assertion; flag tests that query
empty/unpopulated state.
